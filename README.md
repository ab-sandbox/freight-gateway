# Freight Gateway

A freight booking platform focused on enterprise application integration, asynchronous messaging and interoperability between modern and legacy systems.

## Project goals

- Freight order management and validation
- Asynchronous booking requests and responses
- Message routing and transformation
- SOAP and REST carrier integration
- Reliable message processing
- Server-side web portal

## Planned technology stack

- Java 21 / Java 8
- Spring Boot / Spring Framework
- ZK (ZUL, MVVM)
- Hibernate / PostgreSQL / Flyway
- ActiveMQ / JMS
- Mule ESB
- Apache CXF / SOAP
- Docker Compose
